附16.4 CPU 与 GPU 部件对照

CPU 同样具有整数加法器、乘法器、浮点单元和向量执行资源。GPU 的主要变化是在多个 SM 中配置大量并行算术资源，用共同指令处理多份线程数据，并为矩阵等规则运算配置专用单元。这不是在 CPU 后面简单附加一种“GPU 加法器”。

共同基础与 GPU 的扩展方向
部件CPU 是否具有GPU 的配置与作用
整数 ALU／加法器有，用于整数计算、逻辑处理等为大量线程提供并行整数运算；线程索引与地址计算也需要这些能力
浮点加法、乘法与 FMA有，常同时支持标量及 SIMD以多条算术数据通路提升整体吞吐；不保证单次加法延迟更低
特殊函数单元（SFU）CPU 也可有专用数学指令或通过库实现为部分函数提供专门的计算路径；一个完整数学函数可能仍需多条指令
矩阵乘加单元部分 CPU 有，如 AMXTensor Core 面向矩阵块，提升受支持数据类型的密集乘加吞吐

“CUDA Core”是厂商对部分算术资源的命名，不是一个具有独立取指、调度和缓存的 CPU 核心。CPU 的 SIMD 与 GPU 的成组数据通路都利用数据并行；两者的线程语义和调度方式有所不同。

参照 NVIDIA Hopper 架构说明、Intel 向量指令扩展与 Intel AMX。消费级 GPU 与计算型 GPU 的 FP64、矩阵等资源配比可能相差很大，不能仅凭“GPU”名称推断。
