# 教学配图：表达规则与修订记录

更新：2026-09-22。

## 目的

配图应提供正文之外的理解依据，不是给每段文字加方框与箭头。每幅图至少明确表达一种关系：资源包含、数据归属、控制分发、依赖、时间交叠、坐标映射或数量变化。

- 控制与数据：使用不同线型，并以指令和具体数值说明各自携带什么。
- 架构：用边框表达所属范围，用分支区分访问路径；不能把共享内存画成缓存层次的中间一级。
- 流程：箭头必须表示可说明的调用、引用、数据搬运或先后依赖。反馈回路和并行分支应可见。
- 矩阵：优先画行、列、子块位置和累加关系；交互必须改变图形，而不只是替换解释文本。
- 定量关系：使用位宽、坐标或带单位的坐标轴；教学数字与真实规格分别标注。
- 没有独立解释价值的图：删去图框，保留一句必要说明或交叉引用。

示意电路不是实际芯片布线；教学阶段不是物理周期；逻辑线程数不是物理算术单元数量。需要在图注就近说明这些限定，但不重复整章定义。沿用现有书面语气、页面主题及章节顺序。

## 实现与验证

`assets/css/concept-diagrams.css` 为局部图形样式；`assets/js/concept-diagrams.js` 驱动图 2-1。矩阵、驻留状态和附录矩阵实验分别沿用 `assets/js/matrix-chapter.js`、`assets/js/learning-figures.js`、`assets/js/numeric-experiments.js`。所有图形离线可用；窄屏只在图内横向滚动，不压缩到无法辨认的字号。

`node tests/diagram-regression.cjs` 检查本地引用、锚点、SVG 标记、图形结构与模拟 DOM 中的交互结果，并回归既有实验和答题反馈。模拟测试不等于浏览器测试。另将 17 幅 SVG 离线栅格化逐图检查了连线、标签和边界；由于本地浏览器访问受限，未验证完整页面的浏览器渲染。
